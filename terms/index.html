利用規約

最終更新：2026年10月9日

この規約は、ドットパック（以下「本サイト」）を使うときのルールです。本サイトを使った時点で、この規約に同意したものとします。本サイトは KODRAS（以下「運営者」）が運営しています。

第1条 アカウント

  1. 本サイトはログインなしで使えます。初めて開いたときに、名前のないアカウントが自動で作られます。
  2. ログインなしのアカウントは、ブラウザのデータを消すと元に戻せません。Googleアカウントと連携すると、ほかの端末でも同じデータを使えます。
  3. 1人が複数のアカウントを使ってはいけません。

第2条 投稿したドット絵の権利

  1. 投稿したドット絵（カード名・ひとことを含みます。以下「作品」）の著作権は、描いた人（以下「作者」）のものです。運営者に移ることはありません。
  2. 作者は運営者に対して、作品を次の目的で使うことを、無料で、期間の制限なく許可します。この許可は独占的なものではありません。
    • 本サイトでの表示、投票、パックへの収録、図鑑での表示
    • 本サイトの紹介（SNSへの投稿、紹介ページ、ニュース記事など）
    • 今後追加する本サイトの機能（対戦など）で、系統・レアリティ・能力値を付けて使うこと
  3. 上の目的のために、運営者は作品の拡大・縮小、枠や名前・レアリティの表示、シルエット表示などの加工を行うことがあります。作者は、この範囲の利用について著作者人格権を行使しないものとします。
  4. 運営者は、作者の同意なく、作品を単体でグッズにしたり、素材として販売・配布したりしません。
  5. 作者は、自分の作品を本サイトの外でも自由に使えます（販売を含みます）。
  6. 作者は、ほかの利用者が自分の作品を元にした作品を描いて、本サイトに投稿することを許可します（第4条のサイト内二次創作）。

第3条 作品の削除

  1. 投稿の受付期間中は、作者はいつでも自分の作品を削除できます。
  2. 受付期間が終わってパックに収録された作品は、ほかの人の図鑑が欠けないよう、原則として残ります。作者名を表示しないようにすることは、運営者に依頼できます。
  3. 他人の権利を侵害しているなど正当な理由がある場合は、収録後でも削除します。
  4. 削除と作者名の非表示は、第9条のお問い合わせから、作品番号を指定して依頼してください。

第4条 投稿のルール

  1. 次のものは投稿できません。
    • 他人が描いた絵をそのまま写したもの（トレース・転載）。フリー素材の転載を含みます。
    • 性的な表現、過度に暴力的・残酷な表現、差別的な表現
    • 特定の人や団体への誹謗中傷、個人情報
    • 宣伝、政治・宗教の勧誘
    • テーマと関係のない大量の投稿
  2. アニメ・ゲーム・漫画などの既存の作品のキャラクターやロゴ、実在の人物を描いた作品は、投稿と投票はできますが、パックには収録しません。投稿するときに作者が申告するほか、運営者の判断でパックの対象外にすることがあります。
  3. 本サイトに投稿されたほかの人の作品を元にした作品（サイト内二次創作）は、自由に投稿できます。パックにも収録します。

第5条 投票

  1. 投票は1人1アカウントで行ってください。複数のアカウントや自動操作を使った投票は禁止です。
  2. 集計の方法は運営者が決めます。その詳細は公開しない場合があります。
  3. 不正と判断した票は無効にします。集計の結果決まった系統とレアリティについては、運営者の判断を最終とします。

第6条 ほかの人のカード

  1. ほかの人のカードの画面写真を、作者名を添えてSNSなどで紹介するのは自由です（営利目的を除きます）。
  2. ほかの人の作品をそのまま自分の作品として投稿・公開したり、販売・配布したりしてはいけません。サイト内二次創作として本サイトに投稿することは除きます。

第7条 カードとパック

本サイトのカードやパックに金銭的な価値はありません。現金やほかのサービスの品物と交換することは禁止です。

第8条 運営者の対応

この規約に違反した投稿や、違反したと運営者が判断した投稿は、予告なく非表示または削除することがあります。違反を繰り返すアカウントは、利用を止めることがあります。

第9条 お問い合わせ

  1. お問い合わせで受け付けるのは、作品の削除、作者名の非表示、広告のご依頼の3つです。
  2. 作品についてのご依頼は、作品ごとに付いている作品番号を指定し、理由を選んで送ってください。作者名の非表示は、その作品を投稿したアカウントからの依頼に限ります。
  3. 運営者は内容を確認して対応します。広告のご依頼を除き、個別の返信はしません。

第10条 個人情報

  1. 運営者が受け取る情報は、アカウントの識別番号、投稿・投票・集めたカードの記録です。Googleアカウントと連携した場合は、連携のためにGoogleアカウントの識別番号とメールアドレスも受け取ります。メールアドレスは本サイト上には表示しません。
  2. 広告のご依頼では、返信のためにお名前とメールアドレスを受け取ります。返信以外には使いません。
  3. これらの情報は、本サイトの提供と不正の防止のためだけに使います。法令にもとづく場合を除き、第三者には渡しません。
  4. データの保存には Google が提供する Firebase を使います。

第11条 サービスの変更・終了

運営者は、本サイトの内容を変更したり、本サイトを終了したりすることがあります。終了するときは、できるだけ前もってお知らせします。

第12条 免責

運営者は、本サイトの不具合やデータの消失、利用者どうしのトラブルについて、運営者に故意または重大な過失がある場合を除き、責任を負いません。

第13条 規約の変更

運営者はこの規約を変更することがあります。変更後の規約は本サイトに掲載した時点から有効になります。大きな変更はサイト上でお知らせします。

第14条 準拠法と裁判所

この規約は日本の法律にもとづきます。本サイトに関する争いは、東京地方裁判所を第一審の専属的合意管轄裁判所とします。
